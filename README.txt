A.P.J. ABDUL KALAM TRIBUTE WEBSITE

PAGES INCLUDED
- index.html — Home
- early-life.html — Early Life
- scientist.html — The Scientist
- president.html — The President
- books.html — Books & Ideas
- achievements.html — Achievements (searchable)
- quotes-gallery.html — Quotes & Gallery (click images to enlarge)

HOW TO RUN
1. Extract this ZIP file.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Internet access is required for external photos and Google Fonts.
4. All pages share style.css and script.js.

FEATURES
Responsive premium navy/gold/cream UI, separate page navigation, mobile menu, milestone cards, searchable achievements, image gallery lightbox, quotes, timeline, book cards, and responsive layouts.

IMAGE NOTE
Photos are loaded from Unsplash and Wikimedia Commons URLs. Some images are illustrative, not verified archival images of Kalam. Check image source and reuse licences before public or commercial use.
